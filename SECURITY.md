# Reporting sensitive findings

Some evidence shouldn't be posted in a public issue: operating detail for an attack tool, a working way around a defence, or a weakness in a system people rely on.

Report those privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Only the maintainer can see the report.

Please include:

- which study and claim it relates to, if any;
- what you found and how you found it;
- whether it affects a live system or product, and whether its owner already knows.

We'll reply, agree with you what can be published and when, and credit you if you'd like.

This repository has no running services; it holds research. Problems with the scripts can be reported in public issues unless they expose someone's system.
